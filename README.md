# 🍽️ Restaurant Management Chatbot

A simple **Restaurant Management Chatbot** built using **Python and Flask**. The chatbot helps users get information about the restaurant menu, food prices, opening hours, table reservations, delivery, and location.

## ✨ Features

- 🍔 Menu and food information
- 💰 Food price information
- 🪑 Table reservation assistance
- 🕐 Restaurant opening hours
- 🚚 Delivery and takeaway information
- 📍 Restaurant location
- 💬 Interactive chatbot interface
- 🌐 Web-based interface using Flask

## 🛠️ Technologies Used

- **Python**
- **Flask**
- **HTML**
- **CSS**
- **JavaScript**

## 🚀 How to Run

### 1. Install Python

Make sure Python is installed on your computer.

### 2. Install Flask

Open Command Prompt or PowerShell:

```bash
pip install flask
```

### 3. Run the Application

```bash
python app.py
```

### 4. Open in Browser

Go to:

```text
http://127.0.0.1:5000
```

## 💬 Example Questions

You can ask the chatbot:

- `What is on the menu?`
- `How much is the pizza?`
- `What are your opening hours?`
- `I want to book a table`
- `Do you provide delivery?`
- `Where are you located?`

## 🧠 How It Works

The application uses a **Flask backend** to receive messages from the web interface. The chatbot analyzes the user's message using keyword-based logic and returns an appropriate response.

The frontend contains the chat interface and sends user messages to the `/chat` Flask endpoint using JavaScript.
